# 📸 Guide des Photos

## Noms de Fichiers Requis

Place tes photos dans ce dossier avec EXACTEMENT ces noms :

### Timeline (4 photos)
```
✓ rencontre.jpg      → Photo de votre première rencontre
✓ premier-rdv.jpg    → Photo de votre premier rendez-vous  
✓ voyage.jpg         → Photo de votre premier voyage
✓ special.jpg        → Photo d'un moment spécial
```

### Galerie (6 photos)
```
✓ photo1.jpg
✓ photo2.jpg
✓ photo3.jpg
✓ photo4.jpg
✓ photo5.jpg
✓ photo6.jpg
```

## Format Recommandé

- **Format :** JPG ou PNG
- **Timeline :** 1600 x 1200 px (ratio 4:3)
- **Galerie :** 1200 x 1200 px (carré de préférence)
- **Poids :** Moins de 500 KB par image (idéal)

## Compression

Utilise ces outils gratuits pour réduire le poids :
- [TinyPNG](https://tinypng.com/)
- [Squoosh](https://squoosh.app/)
- [iLoveIMG](https://www.iloveimg.com/compress-image)

## Important

⚠️ Les noms sont **sensibles à la casse** (majuscules/minuscules)
⚠️ L'extension doit être `.jpg` (pas `.JPG` ou `.jpeg`)

## Placeholders

Si une photo manque, un placeholder rose avec un cœur s'affichera automatiquement.

Tu peux ajouter les photos plus tard et recharger la page !

---

**Astuce :** Renomme tes photos en masse avec un outil comme [Bulk Rename Utility](https://www.bulkrenameutility.co.uk/) (Windows)
